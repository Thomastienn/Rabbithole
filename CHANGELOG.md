# Changelog

## 1.0.0 — 2026-11-10

First product release. Release evidence and its limits: [docs/verification/product-release.md](docs/verification/product-release.md).

- Branching learning trees: select a passage, ask a question and get a child conversation with a frozen compact context snapshot; branches nest recursively.
- Map: pan, zoom, drag, fold and bulk-fold conversations; compact previews and source-row branch lines; a chat panel beside the map, expanded or full-screen on narrow windows.
- Full keyboard operation, with optional Vim canvas bindings (h j k l, = + -, f).
- Providers: Claude Code (default) and Codex with ChatGPT sign-in, plus one optional OpenAI-compatible custom endpoint. Switch model or provider mid-conversation with history kept.
- Rich replies: Markdown, code and math, with exact passage anchors.
- Tutor-chosen Mermaid diagrams and requested Remotion videos, generated by isolated workers and shown inline in the originating chat.
- Rename and delete chats and branches.
- Local delivery: loopback-only server, local SQLite saves, one `npm start` command with preflight checks.
- Codex turn failures now show the provider's short reason (for example a usage limit) instead of a generic message.

Not in 1.0.0: automatic branch suggestions (Break down), token stats and the knowledge graph; they are planned in the Phase 4 epic.
