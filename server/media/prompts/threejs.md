three.js craft (loaded skill; THREE is the preloaded global, r187, so never import it or use an import map):

- Quick start: create a WebGLRenderer with antialias, set its pixel ratio from devicePixelRatio and its size from the root's width, and append its canvas inside the visual root. Make a Scene, a PerspectiveCamera (field of view about 50–75, near 0.1, far sized to the scene) placed back from the subject, the meshes (geometry plus MeshStandardMaterial), a DirectionalLight placed so it shines toward the origin, and a dim AmbientLight so shadowed faces stay readable.
- Animate with renderer.setAnimationLoop(fn), not requestAnimationFrame. Time motion with THREE.Timer: connect it to document, call timer.update() first in each frame, then read getDelta() or getElapsed(); THREE.Clock is deprecated.
- On resize, update camera.aspect, call camera.updateProjectionMatrix() and renderer.setSize(); size from the root, not the window.
- Clean up on pagehide: renderer.setAnimationLoop(null), dispose each mesh's geometry, its materials and their textures (material.dispose() leaves textures alone, mesh.dispose() frees neither), then renderer.dispose().
- Common mistakes: PCFSoftShadowMap is deprecated (use PCFShadowMap, already soft); outputEncoding and sRGBEncoding are gone (outputColorSpace already defaults to SRGBColorSpace); physicallyCorrectLights and useLegacyLights are gone (light units are always physical, so give point and spot lights candela intensities that suit their distance); mesh.layers.set(n) takes a mesh off layer 0 where the default camera lives (use enable); envMapIntensity scales only the material's own envMap (use scene.environmentIntensity); after editing geometry positions call computeBoundingSphere() or visible objects get culled.
- Keep performance in hand: merge static geometry that shares a material, use InstancedMesh for many copies of one object, and run one animation loop.
