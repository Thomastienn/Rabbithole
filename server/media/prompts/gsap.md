GSAP craft (loaded skill; gsap is the preloaded core global, 3.15, with no plugins, so never import it, register plugins or use ScrollTrigger, Draggable, Flip, SplitText or CustomEase):

- Tweens: gsap.to(targets, vars) animates from the current state, gsap.from() from vars to the current state (good for entrances), gsap.fromTo(targets, from, to) sets both ends, and gsap.set() applies at once. Targets are an element, an array or a selector; scope selectors to the visual root, for example root.querySelectorAll('.bar'), so nothing outside the fragment is touched.
- Vars: duration and delay in seconds (duration defaults to 0.5), ease, stagger (a number of seconds, or { each, from: 'center' }), repeat (-1 for infinite) with yoyo, and onStart, onUpdate and onComplete callbacks. Property names are camelCase.
- Prefer transform aliases over layout properties and the raw transform string: x, y, xPercent, yPercent, scale, rotation and transformOrigin; on SVG, svgOrigin rotates several elements around one point (never with transformOrigin). Use autoAlpha instead of opacity for fades so hidden elements stop taking clicks. Relative values such as x: '+=20' work, and function values get (index, target).
- Eases: only built-in names: 'none', and power1–power4, back, circ, expo, sine, bounce and elastic, each with .in, .out or .inOut ('power1.out' is the default).
- Sequence with gsap.timeline(), not chained delays: pass defaults ({ duration, ease }) to the timeline, and place each tween with the position argument: an absolute time, '+=0.5' after the end, '<' with the previous start, '<0.2' just after it, or a label from addLabel(). Nest timelines with add().
- Keep the returned tween or timeline to control it: play(), pause(), reverse(), restart(), progress(p) and time(s) seek, and kill() stops it. A paused timeline driven by progress() from a slider makes a scrubbable animation.
- Respect reduced motion: gsap.matchMedia() with '(prefers-reduced-motion: reduce)' runs setup only while the query matches and reverts on change; use duration 0 or skip the motion when reduced.
- Mistakes: when several from() or fromTo() tweens set the same property of one element, give the later ones immediateRender: false; from() applies its start values immediately; timeline duration comes from its children; invalid ease names silently fall back.
