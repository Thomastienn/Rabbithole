# Narrated 2D video verification — TreeTutor-133.2

Verified on 2026-11-11 after reading TreeTutor-133, its comments, PRD.md and the final workspace/media specification. TreeTutor-133.1 is closed. This slice adds narration to the existing isolated smart worker, renderer and native player; the library and Three.js remain later slices.

Setup installs pinned `@andresaya/edge-tts` 1.9.1 through npm and provisions Remotion's headless browser. Remotion already ships the ffprobe/ffmpeg binaries used by the application; no Python, offline voice model or narration account/key is required. A source-only temporary checkout ran the normal launcher, installed its locked dependencies, downloaded its own browser, built and served HTTP successfully in 29.566 seconds. Its actual sandbox probe and short audio/subtitle render also passed with these fresh dependencies. This checks a clean project setup on this supported Linux host, where bubblewrap and Chromium's OS libraries already exist; it is not a blank-OS provisioning claim. Browser download failure leaves saved trees/playback usable and explains how to provision on restart. See [setup evidence](narration-clean-setup.json).

The smart worker privately returns a plain spoken script plus freely authored TSX in one response. The server sends only that script to online Edge TTS, saves the returned MP3 and word/sentence timestamps, measures audio with bundled ffprobe, and derives composition length and readable caption groups. Generated visuals receive actual sentence frame boundaries and total duration; the trusted wrapper supplies narration and embedded subtitles. Audio, timing JSON and VTT remain in the owning attempt's private workspace. No transcription call occurs. The renderer receives these assets through read-only mounts, with the existing home/app-data hiding and network isolation. The real boundary probe confirms readable owned audio, denied audio/timing mutation, denied app data/home access and denied external network access.

The old 600-frame composition clamp and 60-second publication check are gone. Actual narration determines duration; the existing 64 KiB composition/200 MiB output budgets remain, with finite synthesis and render budgets that scale with work. Controlled HTTP checks include a measured 125-second narration and prove the provider's old duration export and bitrate estimate cannot shorten it. No replacement fixed product duration cap or unlimited-resource promise is introduced.

Native evidence used Codex subscription adapter `gpt-6.1-terra`, low effort, one native smart call and one Edge synthesis call with `en-US-AriaNeural`. The tutor handoff was controlled; the script, custom visuals, Edge narration, metadata and local sandboxed render were real. Initial synthesis took 3.267 seconds, rendering 123.703 seconds and request-to-ready 188.183 seconds. Reported model counts were input 4,386, output 3,234 and cache-read 4,224; Edge and rendering add no invented LLM tokens. See [native evidence](narrated-video-native-codex.json).
