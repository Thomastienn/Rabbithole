Branded desktop loading screen

Rabbithole-dpl.1. This replaces the plain "Starting Rabbithole…" on white that shows while the desktop app's server starts. Spec: docs/add-ons-updates-and-video-mode-spec.md. Where this mockup and the spec differ, follow the spec.

  • The brand mark draws itself. The trunk leaves its station, two branches fork off, the drawing holds, then it starts again, about every 3 seconds. It shows no progress, because the shell has none to show.
  • Platform colours, the app's default theme, follow the system's light or dark setting. The learner's own theme loads with the app a moment later.
  • Under reduced motion the mark is drawn and still, and only the caption fades slowly.
  • One page, no network. Fonts come from the app's bundled copies, falling back to system fonts. The start error needs no new script: CSS reacts when the shell swaps in its <pre>.
