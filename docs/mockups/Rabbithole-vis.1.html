Visual controls

Rabbithole-vis.1 (input controls) and Rabbithole-vis.2 (display controls). Today every visual builds and styles its own buttons, sliders and readouts. Now the sandbox ships a kit of ready controls, and the worker names one by tag. Spec: docs/visual-controls-play-and-setting-buttons-spec.md, "Visual controls". Where this mockup and the spec differ, follow the spec.

  • Each control is a custom element that renders native elements in the light DOM: a real button, range, checkbox, radio, number or text input. Keyboard, focus and screen readers work as they do for native controls.
  • Every control takes a label, which is its accessible name. Variants use variant. Each exposes value and fires input and change.
  • The base CSS uses only the theme tokens the frame receives, such as --color-accent and --color-text-secondary. It uses only the fonts the sandbox loads: Barlow 400 and 600 for labels and controls, and Atkinson Hyperlegible Next 400 for values and result lines.
  • The kit is quiet. Only the primary button, a pressed toggle, a chosen segment and the slider fill take the accent. Result and status tones colour the icon and the card edge, never the text.
  • No control carries data-part, so clicking one never picks a visual part.
  • Rows wrap at phone width. A slider's track shrinks to 120 px before its value wraps below the label.

In place

A pendulum visual built only from kit controls. The controls work: move the slider, pick a gravity, guess and check, then reset.

A longer string swings more slowly, and weaker gravity slows it too. Try it.

Button

Primary for the one main action, secondary for the rest, quiet for minor ones. A button group lays them out with an 8 px gap and wraps.

<rh-button-group><rh-button label="Run" variant="primary"></rh-button>…</rh-button-group>

Toggle and switch

A toggle is a pressed or unpressed button with aria-pressed; pressed shows a check and the accent. A switch is a checkbox with role="switch", for a setting that is on or off.

<rh-toggle label="Friction" pressed></rh-toggle>  <rh-switch label="Show vectors" checked></rh-switch>

Slider

The label, the track and the live value with its unit, on one line. The fill shows how far along the range the value sits. Arrow keys move one step, Page Up and Page Down ten.

30 °70 °C
<rh-slider label="Angle" min="0" max="90" step="1" unit="°" value="30"></rh-slider>

Number with stepper

For a precise value. Minus and plus step by step and are named after the label. Typing works too; an out-of-range value clamps on change.

kg
<rh-number label="Mass" min="0" step="0.5" unit="kg" value="2.5"></rh-number>

Choice list

Two to five options show as segments. Six or more show as a radio list. Both are native radios in a fieldset, so arrow keys move the choice.

Scale
Planet
<rh-choice label="Planet" options="Mercury,Venus,Earth,Mars,Jupiter,Saturn" value="Earth"></rh-choice>

Text field

When the visual asks the learner to type, such as a word to encode. The label sits before the field, and an optional placeholder gives an example.

<rh-text label="Word to encode" placeholder="e.g. hello"></rh-text>

Readout

A computed value with its unit. The label is small muted caps, and the value is large. It is an output, so a changed value is announced politely. Readouts sit side by side and wrap.

<rh-readout label="Speed" unit="m/s" value="12.4"></rh-readout>

Result card

For a check-yourself answer. Its tone shows on the icon, the edge and a faint tint, and the title says the outcome in words. It is a status region, so the screen reader reads the new outcome.

Correct

On the Moon the period is about 4.9 s, two and a half times Earth's.

Not quite

Weaker gravity makes the swing slower, so the period grows.

Make a guess, then check it

The Moon's gravity is about a sixth of Earth's.

<rh-result variant="correct" title="Correct">On the Moon…</rh-result>

Status

A one-line hint or warning, in body text at reading size. The icon carries the tone, and the text stays ink.

Drag the bob to set the start angle.Balanced: both sides weigh 12 kg.Length must be more than 0. Showing 0.2 m.
<rh-status variant="warning">Length must be more than 0.</rh-status>

Legend

One swatch and label per series, in the series inks: blue, yellow, pink, green. Lines by default; shape="box" for bars and areas. Labels name the series, so colour is never the only cue.

Reset

A quiet button with the circular arrow. It returns every control in the visual to its initial value and fires reset on the root, so the visual redraws.
