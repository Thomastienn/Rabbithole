Free branch from the map

Rabbithole-fbv.3. A conversation node shows a quiet + on hover and on keyboard focus. It opens the branch question box beside the node, with no passage. Sending creates the free branch and opens the child. Spec: docs/free-branch-and-interactive-visuals-spec.md. The spec wins where they differ.

  • The + sits at the right end of the node's title band, in quiet text, 24px. It takes no space at rest: the band looks as it does today.
  • It appears only on a node whose conversation has a completed tutor reply.
  • The box is the branch question box learners already know, minus the quoted passage and the Explain briefly row.
