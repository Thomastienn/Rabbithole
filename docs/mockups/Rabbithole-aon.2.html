Add-ons page in Settings

Rabbithole-aon.2. A new Settings page lists the three add-ons, what each one enables, its download size and its state, with one action per row. The code sandbox is the last row. Spec: docs/add-ons-updates-and-video-mode-spec.md. ADR 0020. Where this mockup and the spec differ, follow the spec.

  • One row per add-on, always in the same order: video tools, offline Python, web search. Nothing is hidden, so the learner sees what they could add.
  • Each row has at most one action: Install, or Retry after a failure. Nothing removes an add-on. A row that is downloading shows its progress bar.
  • Every state is shown in words next to the name, and an icon goes with any state that needs attention. Colour is never the only signal.
  • The video tools row always says it needs offline Python, so the second download is no surprise.
  • Sizes are placeholders. The add-on list gives the real approximate sizes.

The page

A typical mix: offline Python installed, web search downloading, video tools not installed. The nav gains Add-ons between Connections and Usage. Switching pages never moves the scroll (Rabbithole-dpl.2).
