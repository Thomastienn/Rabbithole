First-run setup offers add-ons

Rabbithole-aon.3. First-run setup gets a last step after sign-in and the chat model. It lists the add-ons from the Settings page (Rabbithole-aon.2), with Install on each row, Install all and Skip. Spec: docs/add-ons-updates-and-video-mode-spec.md. Where this mockup and the spec differ, follow the spec.

  • Two steps in one card. Step 1 is sign-in and the chat model. It asks for Claude or Codex, since one is enough, and its main button becomes Continue. Step 2 is the add-ons.
  • The rows are the Add-ons page rows, with the same copy, sizes and states, so the learner meets them again in Settings.
  • Leaving the step never waits. Downloads keep running in the background, and the sidebar tray shows them.
  • The step always says where to find add-ons later, so skipping is safe.

Step 1: one provider is enough

Claude and Codex are alternatives. The card asks for either one, and a provider that is not set up is shown in plain grey, never as an error. Once one is connected, the other is marked optional and its button drops to a quiet one. On Windows the sandbox section stays in this step. The Linux video-packages section is gone: the project wheels remove the need for it (Rabbithole-aon.7), and bubblewrap is reported on the Add-ons page.
