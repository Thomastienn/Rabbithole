Topic colours, hulls and related topics nearby

Rabbithole-mkg.6. Today every topic is the same plain circle, pinned evenly round a ring, so the graph's layout means nothing. Now related topics sit near each other, each concept wears its main topic's hue, and each topic draws a soft hull behind its concepts. Spec: docs/memory-recall-and-knowledge-graph-spec.md, "Graph colour, hulls and placement". Where this mockup and the spec differ, follow the spec.

  • Topic placement comes from the server's PCA anchors, so Mycology sits beside Fermentation and Ecology, and Orbital mechanics sits far away. The same data always gives the same picture.
  • The hue sits on the concept's ring and on its familiarity fill. Empty, half and full fills still mean new, getting there and known.
  • Each hull is one flat shape at low opacity, behind the links and points, with its topic name above it in muted caps. It has no border, gradient or blur.
  • Text never takes the hue. Concept names stay ink, the selected one porcelain, and topic names muted.
  • A concept without a topic stays porcelain, with no hull. "Scientific method" shows this below.
  • The "Merge concepts" button is gone from the page head (Rabbithole-mkg.4), so only Refresh is left.

Neighbouring hues
