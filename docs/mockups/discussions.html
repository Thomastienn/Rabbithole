0. Ground rules for every ticket below

  • Reuse, do not invent. Node chips use Astryx Button (size sm). The discussion card renders lines with Astryx ChatMessage (density compact, as ChatThread.tsx does), Avatar for initials, ChatComposer with elevation="none" and density compact for the reply box, Skeleton for pending and Text type="supporting" for status text. Branching reuses Passage.tsx and BranchForm.tsx unchanged.
  • One frame per object (rule at the top of mock.css). A node is a frame, so its chips use a tonal fill and no border. The discussion card is a frame, so its lines, reply strip and error row use tone, not borders. Only the reply input keeps its stroke.
  • Classmate levels never reach the screen. Not as a badge, colour, order, tooltip, aria-*, data-* or class. All classmate avatars look the same. List the roster in first-speaking order. Recommended: the server leaves level out of the artifact JSON it sends to the browser, so the UI cannot leak it.
  • Colour roles stay. Leaf green (--color-accent) means action and the tutor. Rose red (--color-text-error) means failure only. Series inks are for branch families only, so they never colour a classmate.
