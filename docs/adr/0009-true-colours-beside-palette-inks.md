# Videos may give real objects their true colours beside the palette inks

Every colour in a video came from a fixed kit palette: neutrals and four inks (amber, leaf, rust, lichen), and the plan validator rejected anything else. The rule kept videos looking like one consistent series, but real objects lost the colour that makes them recognisable: in an Artemis video Earth had no blue, the rocket's orange tank became amber and its white boosters became paper. We decided that a video plan may give an object a true colour, a hex value, when the object's real colour carries meaning, while abstract roles such as a highlight, a route or a winner keep the palette inks. The validator accepts a palette role mapped to either an ink or a true colour from the plan, and near-white is allowed. A reused set piece keeps its true colours, while its ink roles are still remapped to the new video's roles. We accepted that videos no longer share one strict palette and that the validator, the house style and the planner prompt each carry a second kind of colour, in exchange for real things that look like themselves.

## Considered Options

- Keep the fixed palette. Fully consistent, but real objects stay unrecognisable and scientific videos look wrong.
- Add more fixed inks, such as a blue and a white. Still consistent, but every real object would have to fit a short list, and the list would keep growing.
- Let the writer pick any colour freely. Most flexible, but colours would drift between cuts and pieces, which the palette roles exist to prevent.
