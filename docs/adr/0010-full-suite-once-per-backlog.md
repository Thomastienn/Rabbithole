# The full suite runs once per backlog, not once per epic

ADR 0007 put a full-suite gate ticket at the end of every epic. Epics are small here, so most runs paid for the fast and slow suites several times, and every epic carried an extra ticket that cost a Ralph iteration to plan and run. We decided that `ralph-afk` makes the gate itself when every epic is out of ready work: a gate epic labelled `gate:backlog` whose one task runs `npm test` and `npm run test:slow`, fixes what it can and files the remaining failures. It makes one only when a task closed after the last gate closed and no gate is still open, so a finished or blocked gate never makes another. Planning sessions create no gate tickets. Each task still ends with `npm run test:affected`. We accepted that a breaking change can sit undetected until the backlog drains, not only until its epic ends.
