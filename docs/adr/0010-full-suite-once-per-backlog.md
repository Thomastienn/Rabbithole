# The full suite runs once per backlog, not once per epic

ADR 0007 put a full-suite gate ticket at the end of every epic. Epics are small here, so most runs paid for the fast and slow suites several times, and every epic carried an extra ticket that cost a Ralph iteration to plan and run. We decided that the backlog holds one open gate ticket, outside any epic, blocked by every other open ticket. It runs `npm test` and `npm run test:slow` once the rest of the backlog is done, fixes what it can and files the remaining failures. Planning sessions add each new ticket as a blocker of the open gate and create a gate when none is open. Each task still ends with `npm run test:affected`. We accepted that a breaking change can sit undetected until the backlog drains, not only until its epic ends.
