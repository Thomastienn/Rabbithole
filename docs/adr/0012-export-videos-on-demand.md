# Videos are saved as playable cuts and exported to MP4 only on demand

ADR 0001 played cuts live and then always rendered a 1080p MP4 in the background for the video library and downloads. That render takes minutes and most of the machine for a file the learner rarely needs, since a video already plays live. We decided that a finished video is saved as its playable cuts, plays live wherever it appears, including the video library, and renders an MP4 only when the learner exports it from the icon at the top right of the player. The exported MP4 is kept, so a second export is instant, and "Show in folder" appears only for exported videos. Videos saved as MP4 before this change count as exported. Writing, narration, Manim clips and cut audits still happen when the video is made, because playback needs them. We accepted a wait at export time and live playback for every saved video in exchange for no render work on videos nobody exports.
